# docs.go-tsvsheet

Public documentation for [`tsvsheet/go-tsvsheet`](https://github.com/tsvsheet/go-tsvsheet) — the [tsvsheet](https://github.com/tsvsheet/tsvsheet) engine as an importable Go library: parse, compute, and inspect `.tsvt` single-file spreadsheets. Published as a [Hugo](https://gohugo.io) site via GitHub Pages at [tsvsheet.github.io/docs.go-tsvsheet](https://tsvsheet.github.io/docs.go-tsvsheet/).
